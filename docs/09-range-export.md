# 시간 구간 내보내기 + 날짜 표기

5차 실기기 피드백 두 건입니다.

---

## 1. `09-09 전체` → `26/09/09 전체`

연도가 빠지면 **월-일인지 일-월인지** 읽는 사람이 판단할 수 없습니다.
`formatShortDate()`를 두어 `YY/MM/DD`로 통일했습니다.

---

## 2. 파일 단위 내보내기는 쓸모가 없었습니다

원본 파일 하나가 **50초**입니다. 그걸 그대로 내보내면 쓸 수 있는 물건이
아닙니다. 게다가 파일명이 `00000440.jdr` — 녹화기가 붙인 순번이라
**언제 찍힌 건지 사람이 알 수 없습니다.**

### 시간으로 자릅니다

"07:57:13부터 08:02:13까지"를 고르면, 그 구간에 걸친 파일 여섯 개를
**하나로 이어 붙여** 내보냅니다.

구간을 정하는 방법은 둘입니다.

- **재생하다가 `[지금]`** — 시작 지점에서 한 번, 끝 지점에서 한 번. 가장 자연스럽습니다
- **시각 직접 입력** — `HH:MM:SS`. 정확히 맞출 때
- 빠른 선택: `현재 파일` `이 운행 전체` `시작+1분` `+5분` `+10분`

고르면 바로 **길이 · 걸친 원본 파일 수 · 대략의 크기**가 나옵니다.
읽기 전에 "이거 몇 GB인가"를 알 수 있어야 합니다.

### 파일명

```
260909_075713-080213_Front.h264
260909_075713-080213_Rear.h264
260909_075713-080213_Audio.wav
260909_075713-080213_GPS.csv
260909_075713-080213_Sensor.csv
```

`YYMMDD_HHMMSS-HHMMSS_종류`입니다. 자정을 넘으면 끝에도 날짜를 붙입니다
(`260909_235000-260910_001200_Front.h264`).

### 영상은 다시 인코딩하지 않습니다 — 그래서 키프레임까지 거슬러 올라갑니다

Annex-B 스트림을 잘라 붙일 뿐이라 **중간 프레임부터 시작하면 참조할 앞
프레임이 없어 화면이 깨집니다.** 그래서 시작 지점 **직전 키프레임**까지
거슬러 올라갑니다.

그 결과 파일이 요청한 시각보다 **몇 초 이르게 시작할 수 있습니다.**
감사 도구에서 이걸 숨기면 안 되므로, 저장할 때 알립니다.

```
260909_075713-080213_Front.h264 저장 · 95.2 MB (키프레임 때문에 1.4초 일찍 시작)
```

### CSV에는 출처 파일이 들어갑니다

여러 파일을 합치면 어느 줄이 어디서 왔는지 알 수 없게 됩니다.
그래서 GPS·G센서 CSV에 `source_file` 열을 넣었습니다.

```
packet_time,gps_time,source_file,pdop,...
2026-09-09 07:57:14.000,...,00000440.jdr,1.2,...
```

### 파일 단위 내보내기는 그대로 둡니다

SHA-256, 분석 요약(JSON), 전체 패킷 목록은 **파일 하나에 대한 사실**이라
구간으로 자를 수 있는 성질이 아닙니다. 내보내기 탭 아래쪽에 그대로 있습니다.
