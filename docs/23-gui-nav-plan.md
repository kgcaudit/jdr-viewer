# 23. 상단바·내비게이션 재설계 + 지도 시각표기 + 이동기록 업로드 계획

세 갈래 요청을 담는다: ① 상단바가 블랙박스 전용이라 이동기록이 혹처럼 붙은 문제,
② 지도 위 GPS 점의 시각 표기, ③ 이동기록 업로드에 폴더 올리기 + 불러오기/저장 정리.

## 1. 상단바 — 페이지마다 바뀌는 맥락 버튼 (핵심)

### 지금 문제
상단바가 `날짜 · ★ · 🔒 · 폴더 · 파일`로 **블랙박스만** 고려한다. 이동기록에
들어가도 폴더·파일 버튼이 그대로 떠 있어 맞지 않고(혹처럼 붙음), 페이지마다
정작 필요한 버튼(대조·목록·인덱스 저장 등)은 본문에 흩어져 있다.

### 제안 — 맥락 상단바 (app shell)
좌: **공간 전환 풀다운**, 우: **그 페이지의 주 버튼 1개 + ⋯ 더보기 메뉴**
(3번 사진의 풀다운 패턴).

```
┌─────────────────────────────────────────────┐
│ ▤ 이동기록 ▾            [주 버튼]   ⋯더보기   │
└─────────────────────────────────────────────┘
        │                              │
   풀다운:                         풀다운:
   · 처음                          · (그 페이지 보조 동작들)
   · 블랙박스
   · 이동기록
```

- **좌측 브랜드 = 공간 전환기.** 누르면 `처음 / 블랙박스 / 이동기록`. 지금 어느
  공간인지 이름으로 보인다. (지금은 로고 누르면 처음으로만 감 → 메뉴로 확장)
- **우측 = 그 페이지 전용.** 주 버튼 1개는 바로, 나머지는 ⋯ 더보기 안에.
  페이지가 바뀌면 우측 버튼 세트가 통째로 바뀐다.

### 페이지별 버튼 배치(안)

| 페이지 | 좌(공간) | 우 주 버튼 | ⋯ 더보기 |
|---|---|---|---|
| 시작화면 | JDR Viewer ▾ | — | — |
| 블랙박스·달력 | 블랙박스 ▾ | 폴더 열기 | 파일 열기 · 인덱스 저장 · 인덱스 갱신 |
| 블랙박스·재생 | 블랙박스 ▾ | 날짜 선택 | ★ 즐겨찾기 · 파일 열기 |
| 이동기록·목록 | 이동기록 ▾ | 위치기록 올리기 | 폴더 올리기 |
| 이동기록·상세 | 이동기록 ▾ | 목록 | 블랙박스와 대조 · CSV · 지우기 |

→ 인덱스 저장/갱신을 달력 본문에서 상단 ⋯로 옮기면 본문이 깔끔해지고,
   버튼이 "제일 좋은 자리(상단)"에서 페이지마다 알맞게 바뀐다.

### 대안 (참고)
- (B) 상단에 공간 탭 두 개(블랙박스|이동기록)를 항상 노출 — 발견성은 좋지만
  좁은 화면 세로를 더 먹는다.
- (C) 좌측 햄버거 → 서랍(drawer)에 내비 전체. 확장성 최고지만 한 번 더 눌러야 함.
- **권장: (A)** — 3번 사진의 풀다운과 가장 가깝고 세로를 안 먹는다.

## 2. 지도 위 GPS 점의 시각 표기

2,000점에 시각을 다 찍으면 글자가 뒤덮여 못 본다. **누르면 그 점 시각을**
보여주는 상호작용이 낫다. 세 겹으로 제안:

- **(기본) 경로를 탭 → 가장 가까운 점의 시각·속도·활동유형 말풍선.** Leaflet
  팝업. 궤적 어디를 눌러도 "몇 시 어디"가 뜬다.
- **시작·끝 지점에 시각 라벨** 상시 표기(출발 08:12, 끝 21:40).
- **(권장 추가) 시간 스크러버** — 지도 아래 슬라이더. 끌면 표식이 궤적을 따라
  움직이고 그 시각을 보여준다. 재생 화면 seek 바처럼 하루를 훑어 위치+시각을
  같이 본다. 뷰어에 이미 있는 `map.syncTo(시각)`를 그대로 쓰므로 붙이기 쉽다.

→ 대조까지 한 상태면 스크러버 표식 색을 판정(주행/보행/체류)으로 칠해
   "이 시각엔 걷는 중"이 한눈에.

## 3. 이동기록 업로드 — 폴더 올리기 + 정리

- **폴더 올리기 추가** — `위치기록 올리기` 옆(또는 ⋯)에 **폴더 올리기**.
  폴더 안 파일을 일괄 파싱해 날짜별 병합. **완전히 같은 점(같은 시각·좌표)은
  중복 제거**(지금 병합 로직이 이미 같은 시각을 하나로 하므로 그대로 걸러짐).
- **파일에서 불러오기 / 파일로 저장 제거** — 캐시(IndexedDB)가 잘 남으니
  평소엔 불필요. 다만 캐시는 브라우저를 지우면 사라지므로, **백업 겸 '파일로
  저장'은 ⋯ 더보기 안에 남겨 둘지**는 정해 주세요(불러오기는 제거).

## 구현 순서 (승인 후)

1. 맥락 상단바 뼈대(공간 풀다운 + 우측 슬롯 + ⋯ 더보기) → 페이지별 버튼 이관.
2. 이동기록 폴더 올리기(webkitdirectory) + 불러오기 제거(저장은 결정대로).
3. 지도 탭-시각 팝업 + 시작·끝 라벨 → (권장) 시간 스크러버.

## 결정 요청

   (B) 공간 탭 상시 / (C) 햄버거 서랍?
2. **지도 시각** — 기본(탭→팝업 + 시작·끝 라벨)만 / **+ 시간 스크러버**(권장)?
3. **이동기록 정리** — 불러오기 제거 확정. **'파일로 저장'은** ⋯에 남길까 /
   완전히 제거할까? (캐시 초기화 대비 백업)
4. **폴더 올리기** — 폴더 통째 업로드 + 같은 점 중복 제거로 OK?
