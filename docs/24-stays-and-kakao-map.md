# 24. 머문 곳(체류) 표기 + 지도 백엔드(카카오/OSM)

두 가지를 함께 넣었다. (1) 이동기록에서 **한 자리에 오래 머문 구간**을 도출해
"머문 시간(시작~끝, N시간 M분)"과 지점을 표기한다. (2) 지도를 **카카오맵 기반**으로
바꾸되, 실기기(`file://`)에서 카카오가 못 뜨는 현실을 감안해 **OSM 대체를 자동**으로
둔다.

## 머문 곳(체류)

- `core/stays.ts` — `deriveStays(points)`가 시각 순 점들을 훑어 **반경 안에 연속으로
  머문 묶음**을 체류 하나로 만든다. 기본값: 반경 60 m, 최소 5분. 묶음의 시각 폭이
  최소 시간을 넘어야 체류로 남긴다(이동 구간은 묶음이 1점이라 걸러진다).
- 왜 점의 `staytime` 필드가 아니라 궤적에서 도출하나 — `staytime`은 점 하나에 붙은
  값이라 "언제부터 언제까지"가 안 나온다. 연속 점을 묶으면 시작~끝이 명확하다.
- 표기: 상세 화면에 **머문 곳** 표(시각범위 · 머문 시간 · 장소)와 합계(N곳 · 총 시간),
  지도에는 굵은 표식 + 머문 시간 라벨(누르면 시각 범위·주소).
- 주소는 도와줘 기록에 `address`가 있으면 대표 주소로 담는다(`MovePoint.addr`).

## 지도 백엔드

`ui/map-backend.ts`의 `MapBackend` 한 인터페이스를 두 구현이 만족한다.

- `ui/map.ts` `LeafletBackend` — OSM 타일. **API 키·도메인 등록 불필요.**
- `ui/kakao.ts` `KakaoBackend` — 카카오 JS SDK. 국내 지도(감사에 유리).
- `ui/map.ts` `GpsMap` — 파사드. 실행 환경에 맞는 백엔드를 골라 호출부에서 감춘다.
  카카오 생성이 어긋나면 즉시 OSM 으로 내려앉는다(안전제일).

### 카카오는 언제 뜨나 — 그리고 왜 실기기에선 OSM 인가

제공된 `KAKAO_API_GUIDE`가 못박은 제약:

- **JS 키는 개발자센터에 등록한 도메인에서만 동작한다(§2).**
- 카카오 지도는 **국내 타일만** 준다(§3). 해외/대체는 Leaflet+OSM.

이 앱의 실제 배포는 **안드로이드 다운로드 폴더에서 `file://` 로 여는 단일 HTML**이다.
`file://`는 등록할 도메인이 없고 출처(origin)가 null 이라 카카오 SDK 인증이 막힌다.
그래서 `preloadKakao()`는 **http/https 이고 localhost 가 아닐 때만** SDK 를 부른다.
그 외(파일 열기·localhost·오프라인·미등록)에서는 부르지 않고 OSM 으로 결정론적으로
떨어진다 — 실기기·헤드리스 e2e 가 늘 OSM 을 탄다.

정리:

| 여는 방식 | 지도 |
|---|---|
| 등록 도메인의 http/https | 카카오 |
| `file://` (실기기 다운로드) | OSM |
| localhost / 오프라인 / 미등록 | OSM |

**즉 지금 배포 방식(파일 열기)에서는 화면상 OSM 이 뜬다.** 카카오 지도를 실제로
쓰려면 이 단일 HTML 을 카카오 콘솔에 등록한 도메인에서 http(s)로 서빙해야 한다.
코드는 그 환경을 자동 감지해 카카오로 전환하도록 이미 준비돼 있다.

키: JS 키는 브라우저에 노출되는 값이라 도메인 제한이 유일한 보호막이다. REST 키
(주소→좌표)는 브라우저 CORS·null 출처로 `file://`에서 막히므로 클라이언트에 넣지
않았다 — 주소 라벨은 도와줘 기록의 `address`를 그대로 쓴다.
